# RUROO™ - Global Private Label & Dropshipping Manufacturing

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

**RUROO** is an ultra-modern, high-converting B2B Private Label Dropshipping & Contract Manufacturing platform inspired by [tymk.world](https://tymk.world/) and tailored with 2026 luxury dark-mode aesthetics, custom 3D branding, and interactive e-commerce tools.

---

## 🌟 Key Features

- **3,500+ Ready Formulations**: Skincare, Color Cosmetics, French Luxury Perfumes, Hair & Scalp Care, Pet Grooming, and Daily Nutraceuticals.
- **24–48h Automated Blind Dropshipping**: Orders are packed with custom branded packaging, tissue wrap, and blind-shipped worldwide.
- **Interactive Profit & Margin Calculator**: Real-time financial estimation of wholesale unit cost, custom packaging, blind fulfillment fees, gross margin %, and monthly/annual projected net profits.
- **Filterable Formulation Catalog**: Fast category switching, live instant search with drop-down previews, and comprehensive Quick View specification modals.
- **Slide-Over RFQ & Sample Kit Drawer**: Persistent cart allowing brands to select sample formulations and submit instant quotation requests.
- **Live Multi-Currency Switcher**: Real-time dynamic price conversion between USD ($), EUR (€), GBP (£), and INR (₹).
- **Manufacturing Facility Showcase**: Automated rotary filling lines, ISO Class-7 sterile cleanrooms, and stability testing labs.
- **Global Fulfillment Map**: Regional express delivery speeds across North America, UK, Europe, UAE, India, and Australia.

## 🚀 Getting Started

### Local Development
Clone the repository and start the lightweight built-in server:

```bash
git clone https://github.com/aangi969/ruroo.git
cd ruroo
node server.js
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Deployment to Vercel

Deploy instantly using the Vercel CLI or Git integration:

```bash
npx vercel
```

Or connect this repository directly in the [Vercel Dashboard](https://vercel.com/new).
